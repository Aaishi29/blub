# Blub Ocean Journal - Background Music Tracks

Drop your downloaded ElevenMusic track files in this directory (`public/music/`).
The app will automatically detect them and play the configured timestamp loop when the **Music** button is toggled ON.

### Required Tracks & Filenames:

1. **Track 1: Sunlit Currents**
   - URL: https://elevenmusic.io/tracks/VNrYiGLOJQ9eCnOp
   - Accepted filenames:
     - `VNrYiGLOJQ9eCnOp.mp3` (or `.m4a` / `.wav`)
     - `bright.mp3`
     - `sunlight.mp3`
     - `sunlit_currents.mp3`
   - Loops used:
     - **Bright (Sunlight)**: 0:33 - 0:41 on loop
     - **Warm (Twilight)**: 0:02 - 0:08 on loop

2. **Track 2: Balance Point**
   - URL: https://elevenmusic.io/tracks/hAUOagzqlB1XUDfL
   - Accepted filenames:
     - `hAUOagzqlB1XUDfL.mp3` (or `.m4a` / `.wav`)
     - `even.mp3`
     - `midnight.mp3`
     - `balance_point.mp3`
   - Loops used:
     - **Even (Midnight)**: 0:22 - 0:34 on loop
     - **Down (Abyss)**: 0:01 - 0:11 on loop

3. **Track 3: Sunlit Serenity**
   - URL: https://elevenmusic.io/tracks/TIxWMVoAMXSZ4D5b
   - Accepted filenames:
     - `TIxWMVoAMXSZ4D5b.mp3` (or `.m4a` / `.wav`)
